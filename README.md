# 혈당 조절 시뮬레이터

우리 몸이 혈당을 어떻게 맞추는지 **움직이는 몸속 지도**로 보여주는 학습용 웹앱입니다.

**바로 보기:** https://sihuny227-rgb.github.io/glucose-simulator/

## 무엇을 볼 수 있나

- **4가지 상황**: 탄수화물 식사 · 공복(밤사이~72시간) · 단백질 식사 · 운동
  - 상황마다 6~7단계로 나눠 포도당·인슐린·글루카곤·GLP-1/GIP·아드레날린·지방산·케톤체가 어느 장기에서 나와 어디로 가는지 보여줍니다.
- **몸 상태 비교**: 정상인 / 제2형 당뇨병 / 제1형 당뇨병(인슐린 부족 상태)
  - 단계마다 당뇨병에서 무엇이 달라지는지 설명하고, 혈당 곡선을 정상인과 겹쳐 그립니다.
- **약물 작용**: 메트포르민, SGLT2 억제제, DPP-4 억제제, GLP-1 작용제, 터제파타이드, 설포닐우레아, 글리니드, TZD, α-GI, 인슐린
  - 「약 없이 ↔ 약 복용」을 바꿔 가며 각 약이 고장 난 지점 중 어디를 고치는지 비교합니다.
  - 대표 성분·제품명, 혈당강하·체중·저혈당, 복약 포인트를 함께 보여줍니다.

휴대폰과 PC 모두에서 동작하고, 다크 모드를 지원합니다. 키보드 ← → 로 단계를 넘길 수 있습니다.

## 파일

설치나 빌드 없이 `index.html` 파일 하나로 동작합니다. 글꼴만 Google Fonts에서 불러옵니다.

## 근거와 주의

- 내용은 「당뇨병의 병태생리」 학습 자료(ADA Standards of Care in Diabetes 2026, 대한당뇨병학회 2025 진료지침, Endotext Glucagon Physiology 등 인용)를 바탕으로 했습니다.
- 혈당 곡선, 입자 수, 호르몬 막대는 원리를 보여주기 위한 **개념적 예시**이며 실측값이 아닙니다.
- 약학 교육·복약지도 학습용 자료입니다. 실제 진단·치료·약물 선택은 개별 임상 평가와 최신 허가사항을 확인해야 합니다.
